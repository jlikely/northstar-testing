# How to add a competitive program

This guide covers adding a competitive program (e.g. "Academy," "Developmental
Academy"). Every step happens inside the normal WordPress dashboard — no
developer or code needed.

---

## 1. Create the program

1. Go to **Programs → Add New**.
2. Title: the program's name, e.g. "Academy." This is what shows up as the
   card title everywhere on the site.

## 2. Fill in the basics

Scroll down to the **Program Details** box below the title. Fill in whatever
applies (leave the rest blank — blank fields just don't show up on the page):

- **Age Range** — e.g. "U13–U19"
- **Tryout Required** — check this box if one is needed (common for
  competitive programs)
- **Format** — e.g. "11v11" or "7v7 indoor"
- **Venue / Location** — where it's held
- **Cost** — a simple price if there's just one and it doesn't vary by
  session (see step 4 if it does)

## 3. Write the description

In the **Notes** field (further down, under "Extra Sections"), write the
program's description — what it is, who it's for, tryout details, division
info, anything a parent needs to know up front. This shows as a callout box
on the page.

## 4. Does the price or dates change depending on the time of year?

This is the important part for competitive programs specifically, since many
run in more than one seasonal window with different pricing (e.g. a Spring
session that costs more than a shorter Fall session).

**If the program is identical every time it runs** (same price, just
different dates), you don't need anything special — just check every season
it runs in (step 6) and put the general info in Cost/Notes above.

**If the price, dates, or details genuinely differ by session or season**,
use the **Sessions** section instead of the single Cost field above: click
**Add** once per session/season and fill in:

- **Session Name** — e.g. "Spring/Summer" or "Fall," or "Session I" /
  "Session II" for programs that run in several chunks within one season
- **Dates** — that session's specific date range
- **Cost** — that session's specific price (leave the program-level Cost
  field above blank if it varies like this)
- **Note (optional)** — anything specific to that session only — a
  different uniform, an age-range note, registration-window details, special
  schedule notes. This is exactly where session-specific facts belong instead
  of the shared Notes box in step 3, which should stay to what's true
  year-round.

This is the single-source mechanism for "the same program, but the details
change by season" — one program entry, multiple Sessions rows, instead of a
separate program per season.

## 5. Set up registration

Scroll to the **Registration** section:

- **Registration Window** — e.g. "Opens June 1"
- **Registration Note** — any extra context (or leave this for each
  session's own Note if it varies by session — see step 4)
- Fill in whichever registration link(s) apply: **Team / Individual**, or
  **Boys / Girls** if registration is split by gender. Only fill in the ones
  that apply — the site shows the right buttons automatically.

## 6. Tag the program — this is what makes it show up on the site

Scroll to the right sidebar, where you'll see three checkbox lists:

- **Seasons** — check **every season this program actually runs in.** Don't
  create a second copy of the same program just to put it on a different
  season page — check every applicable box on this one entry instead (and if
  the details differ by season, that's what step 4's Sessions are for).
- **Levels** — check **Competitive**.
- **Locations** — check whichever location(s) this program is offered at.

## 7. Publish

Click **Publish**. The program will automatically appear as a card on every
season page matching the Seasons/Levels/Locations you checked.

## 8. Double-check

Visit each season page you expected this program to appear on and confirm
the card shows up, links correctly, and — if you used Sessions in step 4 —
that each session's dates/cost/notes look right.

---

## Good to know

- **One program, every season it runs in — never one copy per season**, even
  when the price or dates change season to season. That's what Sessions is
  for (step 4).
- **Two programs sharing a name but running at genuinely different times
  with different real content are still one program, not two** — use
  Sessions to hold each version's specifics rather than creating a lookalike
  duplicate. If you're not sure whether something is "the same program with
  different sessions" or truly two different programs, ask: is it the same
  offering a parent would recognize as one thing, just at a different time of
  year? If yes, it's one program with multiple sessions.
- **Financial aid text is shared sitewide** — check **Show Financial
  Assistance Section** to show it; you don't need to type the wording
  yourself.
- If a program is really **two or more differently-priced sub-offerings**
  bundled under one page (not just the same offering at a different time of
  year, but genuinely different named offerings — like "Lil Dribblers" and
  "Junior Kickers" under "Kickstarters"), that's a different, more involved
  setup. See
  [adding-a-recreational-program-with-sub-programs.md](adding-a-recreational-program-with-sub-programs.md)
  — the same Sub-programs field works for competitive programs too, it just
  hasn't come up yet on the competitive side.
