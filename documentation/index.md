# Site management docs

Plain-language guides for managing the North Star FC website — no developer
or code needed for anything listed below. Grouped by area.

---

## Locations

- **[adding-a-location.md](adding-a-location.md)** — how to add a new North
  Star FC location (e.g. a 5th city).
- **[removing-a-location.md](removing-a-location.md)** — how to pause a
  location (safe, reversible) or permanently remove one (destructive —
  full asset checklist).

## Youth Soccer — Recreational programs

- **[adding-a-recreational-program.md](adding-a-recreational-program.md)** —
  the common case: a single program, one age range, one price, one schedule.
- **[adding-a-recreational-program-with-sub-programs.md](adding-a-recreational-program-with-sub-programs.md)**
  — when a program is really two or more named offerings bundled together
  (e.g. "Kickstarters" = "Lil Dribblers" + "Junior Kickers"), each with its
  own price, schedule, and Register button.

## Youth Soccer — Competitive programs

- **[adding-a-competitive-program.md](adding-a-competitive-program.md)** —
  adding a competitive program, including how to handle one that runs in
  more than one season with different pricing/dates (e.g. Academy tiers)
  without creating duplicate entries.

## Youth Soccer — Leagues

- **[adding-a-league.md](adding-a-league.md)** — league-style programs that
  run as a series of sessions within one season (e.g. Youth League age
  tiers). Cross-references the competitive doc above for how Sessions work.

## Youth Soccer — Camps

- **[adding-a-camp-session.md](adding-a-camp-session.md)** — the common
  task: adding a new date range of an existing camp. Also explains the
  Season / Level / Location / Camp Type tagging every camp needs.
- **[adding-a-camp-type.md](adding-a-camp-type.md)** — the rarer task:
  introducing a genuinely new *kind* of camp and writing its shared
  description (shown in every session of that type's "more info" popup).

## Planned, not built yet

- **[simple-content-page-plan.md](simple-content-page-plan.md)** — a design
  for making simple static pages (Tryouts, Club, Resources, Events, Field
  Maps, Soccer Store) self-serve. Not started — Youth Soccer content is the
  current priority. Read this before building that area so the design isn't
  re-derived from scratch.

---

## Not documented yet

These areas exist on the site but haven't been through the same
self-serve review as everything above:

- **Adult Soccer** (Coed Leagues, Women's League, etc.) — currently
  placeholder pages with no real content; revisit once there's real content
  to work with.
- **Removing** a program, camp, camp type, or league — only Locations has a
  removal guide so far.
