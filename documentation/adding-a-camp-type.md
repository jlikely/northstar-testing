# How to add a new camp type

A **camp type** is the *kind* of camp — Technical, Goalkeeper, World Cup, and
so on. Each type has one shared description (an intro paragraph plus a list
of highlights) that shows up in the "more info" popup for every session of
that type. This is a much rarer task than adding a camp session — most of
the time the camp type you need already exists (see
[adding-a-camp-session.md](adding-a-camp-session.md)). Use this guide only
when you're introducing a genuinely new kind of camp that's never been
offered before.

Every step happens inside the normal WordPress dashboard — no developer or
code needed.

---

## 1. Create the camp type

1. Go to **Camp Sessions → Camp Types**.
2. Click **Add New Camp Type**.
3. Name it, e.g. "Speed & Agility." Save.

## 2. Write its description

1. Find the new type in the list and click **Edit** (or **Quick Edit** won't
   show this — use the full **Edit** link).
2. You'll see a **Camp Type Description** box with:
   - **Intro** — a paragraph introducing this kind of camp. This is the main
     text shown at the top of the "more info" popup for every session of
     this type.
   - **Highlights** (optional) — click **Add** once per highlight, and fill
     in a short **Title** and **Text** for each, e.g. Title: "Ball Control,"
     Text: "Players learn how to receive and control the ball using
     different parts of their body." Add as many as make sense — three or
     four is typical.
3. Update.

## 3. Use it

Now that the type exists with a real description, go add camp sessions of
this type — see [adding-a-camp-session.md](adding-a-camp-session.md). Each
session you tag with this Camp Type will automatically show this same
description in its "more info" popup.

---

## Good to know

- **One description, every session of that type.** If you edit the Intro or
  Highlights later, every camp session tagged with this type updates at
  once — you're not editing anything on the individual camp sessions
  themselves.
- **If a type has no description filled in yet**, its "more info" popup
  just shows "Details coming soon." instead of erroring — so it's safe to
  create the type first and come back to write the description later if
  you're not ready yet, though it's better to fill it in before publishing
  any real sessions of that type.
