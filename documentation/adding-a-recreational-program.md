# How to add a recreational program

This guide covers the standard case: a single program with one age range,
one price, and one schedule (e.g. "Fall Rec League," "Top Soccer Classes").

If what you're adding is really **two or more named offerings bundled
together** — each with its own age range, price, and schedule (like
"Kickstarters," which is really "Lil Dribblers" + "Junior Kickers") — use
[adding-a-recreational-program-with-sub-programs.md](adding-a-recreational-program-with-sub-programs.md)
instead.

Every step happens inside the normal WordPress dashboard — no developer or
code needed.

---

## 1. Create the program

1. Go to **Programs → Add New**.
2. Title: the program's name, e.g. "Fall Rec League." This is what shows up
   as the card title everywhere on the site.

## 2. Fill in the basics

Scroll down to the **Program Details** box below the title. Fill in whatever
applies (leave the rest blank — blank fields just don't show up on the page):

- **Age Range** — e.g. "Ages 9–12"
- **Dates** — e.g. "September–November"
- **Tryout Required** — check this box if one is needed
- **Format** — e.g. "11v11" or "Small-sided"
- **Venue / Location** — where it's held
- **Cost** — a simple price if there's just one. If pricing varies by grade,
  use the **Grade-Based Costs** table further down instead (one row per
  grade), or **Tiered Pricing** if there's an early-bird vs. general price.

## 3. Add the schedule (if it has one)

Further down, **Practices** and **Games** each have their own day, location,
and optional dates. Leave both blank if this program doesn't have a
practice/game schedule (e.g. a drop-in class) — use **Sessions** instead (see
next).

## 4. Add sessions (if it runs in date-limited chunks)

If the program runs as a series of named sessions rather than an ongoing
season (e.g. "Winter Session I — October"), use the **Sessions** section:
click **Add**, give it a name, dates, cost, and an optional note.

## 5. Set up registration

Scroll to the **Registration** section:

- **Registration Window** — e.g. "Opens June 1"
- **Registration Note** — any extra context
- Fill in whichever registration link(s) apply: **Boys / Girls** (two
  separate links), or **Team / Individual**. Only fill in the ones that
  apply — the site shows the right buttons automatically based on what's
  filled in.

If there's coaching signup info for this program, check **Show Coaches
Column** and fill in the coaching note and contact link — this shows a
"Coaches" section next to the player registration buttons.

## 6. Tag the program — this is what makes it show up on the site

Scroll to the right sidebar, where you'll see three checkbox lists:

- **Seasons** — check **every season this program actually runs in.** This
  is important: if the exact same program runs in both Fall and
  Spring/Summer, don't create it twice — check both boxes on this one entry.
  It'll automatically show up on both season pages. Creating a second copy
  for the second season is exactly the duplicate content we're trying to
  avoid — one entry, multiple seasons checked.
- **Levels** — check **Recreational**.
- **Locations** — check whichever location(s) this program is offered at.

## 7. Publish

Click **Publish**. The program will automatically appear as a card on every
season page matching the Seasons/Levels/Locations you checked — nothing else
needs to be touched.

## 8. Double-check

Visit each season page you expected this program to appear on (e.g.
`/youth-soccer/rochester/recreational/fall/` and
`/youth-soccer/rochester/recreational/spring-summer/` if you checked both)
and confirm the card shows up and links to a page with the right details.

---

## Good to know

- **One program, every season it runs in — never one copy per season.** The
  Seasons checkboxes are the whole mechanism for this. If you ever find
  yourself about to create a second copy of a program just to put it on a
  different season page, stop — go check the extra season box on the
  original instead.
- **Financial aid text is shared sitewide** — if this program should show the
  financial assistance section, just check **Show Financial Assistance
  Section**; the actual wording is managed in one place and you don't need to
  type it out here.
